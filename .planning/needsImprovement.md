# YaChiYo 桌寵專案 — 需改進項目

> 最後更新：2026-04-26

---

## 🔴 高優先級

### 1. AI 通訊端點不一致 [ ]
- **問題**：Qt 端發送 POST 至 `/transform`（`mainwindow.cpp` L445），但 Python 後端只定義了 `/generate`（`inference.py` L15）
- **影響**：AI 通訊功能完全無法運作
- **建議**：統一端點名稱，兩側對齊

### 2. AI 錯誤處理不足 [ ]
- **問題**：`onAIResultReceived()` 在收到錯誤時只做 `deleteLater()` 就直接切回 Standing，沒有任何錯誤通知
- **影響**：使用者看不到 AI 失敗原因（網路斷線、後端未啟動、模型載入失敗等）
- **建議**：加入錯誤提示（如 tooltip / 狀態動畫），並在 debug 面板中顯示錯誤訊息

### 3. AI 請求缺少觸發入口 [ ]
- **問題**：`requestAIProcessing()` 函數已實作，但在整個程式中沒有任何地方呼叫它（右鍵選單、快捷鍵等都沒有）
- **影響**：使用者無法觸發 AI 功能
- **建議**：在右鍵選單加入「AI 變身」等選項，或設計其他互動觸發方式

## 🟡 中優先級

### 1. Flying / Hovering 狀態未實作 [ ]
- **問題**：狀態機中 `Flying`（feat-1）和 `Hovering`（feat-2）只有空殼，`updatePhysics()` 中沒有實際邏輯
- **影響**：桌寵行為單調，只有站立和走路
- **建議**：優先實作 Hovering（Sin Wave 浮動），增加視覺趣味

### 2. 設定分頁完全為空 [ ]
- **問題**：SettingsCenter 的「設定 (Settings)」分頁沒有任何控制項
- **影響**：使用者無法自訂任何參數
- **建議**：至少加入以下設定：
  - 行走速度調整
  - 決策間隔調整
  - 桌寵大小縮放
  - 重力強度
  - 是否置頂

### 3. 動畫資源不完整 [ ]
- **問題**：
  - 只有 Walking 有序列幀動畫，Standing 和 Captured 只有靜態圖
  - 已有 `Captured.gif` 但程式碼中 GIF 載入邏輯（`loadAnimation()`）已被整段註解掉（`mainwindow.cpp` L167-185）
  - `petSkinType` 變數宣告了但從未被使用
- **影響**：Captured 狀態沒有動畫反饋，互動感弱
- **建議**：啟用 GIF 支援或為所有狀態製作序列幀

### 4. 行為決策計時器註解與實際不一致
- **問題**：`behaviorTimer->start(5000)` 的註解寫「每 3s 執行一次」，但實際是 5 秒
- **影響**：維護者可能誤判邏輯
- **建議**：修正註解或將間隔改為可配置

## 🟢 低優先級（代碼品質）

### 1. 未使用多螢幕支援 [ ]
- **問題**：所有螢幕計算都使用 `primaryScreen()`，拖曳桌寵到副螢幕時邊界偵測會錯誤
- **建議**：使用 `QGuiApplication::screenAt()` 取得桌寵實際所在螢幕

### 2. 記憶體管理疑慮 [ ]
- **問題**：`imageSwitchTimer` 使用 `new QTimer` 而非 `new QTimer(this)`（`mainwindow.cpp` L60），缺少父物件管理
- **影響**：潛在記憶體洩漏風險
- **建議**：改為 `new QTimer(this)` 以自動管理生命週期

### 3. 硬編碼數值過多 [ ]
- **問題**：重力、回彈係數、圖片大小(250)、行走速度、決策間隔等全部硬編碼為 `const` 成員變數
- **影響**：調整參數需重新編譯，無法讓使用者自訂
- **建議**：抽取為配置檔（JSON/INI）或連接到設定中心 UI

### 4. UI 佈局使用絕對座標 [ ]
- **問題**：`settingscenter.ui` 中 `buttonBox` 和 `tabWidget` 使用固定座標定位，未使用佈局管理器
- **影響**：視窗縮放時 UI 元件不會自動適應
- **建議**：改用 QVBoxLayout / QGridLayout 管理整個對話框

### 5. 缺少系統托盤整合 [ ]
- **問題**：關閉桌寵後無法重新啟動，需要重新執行程式
- **建議**：加入 `QSystemTrayIcon`，提供最小化到托盤 / 重新顯示 / 退出等功能

### 6. 缺少音效系統 [ ]
- **問題**：所有互動（拖曳、落地、走路、碰牆）都沒有音效
- **建議**：整合 `QSoundEffect` 或 Qt Multimedia 模組，增加互動回饋

### 7. 缺乏國際化支援 [ ]
- **問題**：右鍵選單文字（「設定中心」、「關閉桌寵」）和設定中心 UI 皆為硬編碼中文
- **建議**：導入 Qt Linguist (`tr()`) 支援多語系

### 8. MainWindow UI 設計冗餘 [ ]
- **問題**：`mainwindow.ui` 包含 `QMenuBar` 和 `QStatusBar`，但視窗已設定為無邊框透明，這些元件永遠看不到
- **建議**：移除不需要的元件，減少資源消耗
