# iPhone 捷徑「八千代」設定步驟（To-do Item 17）

> 流程：聽寫 → Claude API 回覆 → 朗讀 → 紀錄先存手機 → 送到電腦 → 送成功就清空手機暫存
> 狀態：✅ 2026-10-26 端到端實測成功（iPhone 13 → Tailscale → `inbox.md`）
> 電腦端：`tools/note_receiver.py`（Tailscale `100.102.217.57:39220`）

---

## 0. 事前準備

1. **Claude API 金鑰**：建議到 Anthropic Console **另開一把專用金鑰並設花費上限**，外流時可單獨撤銷。
2. **接收器 token**：電腦上打開 `C:\Users\User\AppData\Local\YaChiYo\phone\token.txt`，複製裡面那一行。
   （傳到手機的方式自選，例如貼到只有自己看得到的地方，用完刪掉。）
3. iPhone 的 Tailscale 保持連線（可在 Tailscale App 開「On Demand」自動連線）。

> ⚠️ 兩把金鑰會寫在捷徑裡 → **這個捷徑不要分享給任何人**。

## 1. 新增捷徑，命名「八千代」

依序加入下列動作（括號內是英文名稱，搜尋不到中文時可用）：

### A. 聽你說話
1. **聽寫文字**（Dictate Text）
   - 語言：中文（台灣）
   - 停止聽寫：暫停後

### B. 問 Claude
2. **文字**（Text）→ 貼上 Claude API 金鑰。長按這個動作改名為「Claude 金鑰」較好認。
3. **取得 URL 內容**（Get Contents of URL）
   - URL：`https://api.anthropic.com/v1/messages`
   - 方法：**POST**
   - 標頭（Headers）新增三個：
     | 鍵 | 值 |
     |---|---|
     | `x-api-key` | 變數「Claude 金鑰」 |
     | `anthropic-version` | `2026-10-21` |
     | `content-type` | `application/json` |
   - 要求本文：**JSON**，新增欄位：
     | 鍵 | 類型 | 值 |
     |---|---|---|
     | `model` | 文字 | `claude-haiku-5-5` |
     | `max_tokens` | 數字 | `1024` |
     | `thinking` | 辭典 | 裡面一個鍵 `type`（文字）= `disabled` |
     | `system` | 文字 | 角色設定，見下方範例 |
     | `messages` | 陣列 | 裡面一個**辭典**：`role`（文字）= `user`、`content`（文字）= 變數「已聽寫的文字」 |

   `system` 範例（可改成 Hermes 裡八千代的設定）：
   ```
   你是八千代，使用者的桌寵助理。用繁體中文、口語、簡短回答（兩三句以內），因為回覆會被朗讀出來。
   ```

### C. 取出回覆並朗讀
4. **取得辭典值**（Get Dictionary Value）→ 取得「content」的值，來源是「URL 的內容」
5. **從列表取得項目**（Get Item from List）→ 第一個項目
6. **取得辭典值** → 取得「text」的值
7. **朗讀文字**（Speak Text）→ 朗讀步驟 6 的「辭典值」，語言選中文（台灣）

> `thinking` 一定要設 `disabled`：不然第一個項目會是空的思考區塊，捷徑會什麼都不念。

### D. 紀錄先存手機
8. **文字** → 組成這次的紀錄（變數用插入的方式）：
   ```
   [目前日期] 我：已聽寫的文字
   八千代：辭典值
   ```
   「目前日期」點開後把格式改成「自訂」：`yyyy-MM-dd HH:mm`
9. **附加到文字檔案**（Append to Text File）
   - 「將 文字 附加到 **我的 iPhone**」：⚠️ 位置要選「我的 iPhone」，不要選 iCloud Drive
   - 檔案路徑：`inbox.txt`
   - 打開「**新增一行**」（每筆紀錄另起一行；找不到就在步驟 8 文字最後多按一次 Enter）

### E. 送到電腦，成功就清空
> 「附加到文字檔案」的輸出「**已附加的檔案**」就是 `inbox.txt` 本身，不需要再「取得檔案」
> （加了「取得檔案」反而會把資料夾欄位自動帶成這個檔案，報「檔案路徑必須包含在目錄內」）。

10. **從輸入取得文字**（Get Text from Input）→ 輸入選「已附加的檔案」，確保送出的是檔案內容而不是檔名
11. **文字** → 貼上接收器 token（前後不要有空白或換行）
12. **取得 URL 內容**
    - URL：`http://100.102.217.57:39220/note`
    - 方法：**POST**
    - 標頭：`Authorization` = `Bearer ` + 步驟 11 的「文字」（**Bearer 後面有一個空格**）
    - 要求本文：**JSON**，一個欄位 `text`（文字）= 步驟 10 的「文字」
13. **如果**（If）→ 步驟 12 的「URL 內容」**包含** `true`
    - 若選單只有「包含任何數值」：在前面加「從輸入取得文字」把 URL 內容轉成文字，條件改用那個「文字」
    - 裡面放 **刪除** → 對象選「**已附加的檔案**」，展開 › 關閉「確認刪除」
    - （可選）**顯示通知**：「已送到電腦 ✓」
    - 「否則」留空或刪掉
14. 結束如果

> ⚠️ 多個動作的輸出同名（好幾個「文字」「辭典值」「URL 內容」），而且「文字」動作不一定能改名 →
> 插入變數時選**最近的那一個**，選完再確認。

## 2. 設定喚醒方式（擇一或都設）

- **語音快捷指令**（不用先說「嘿 Siri」）：設定 › 輔助使用 › 語音快捷指令 › 設定 → 選捷徑「八千代」→ 念三次「八千代」訓練。
  ⚠️ 中文喚醒詞能不能辨識還沒驗證過，這次一起實測。
- **背面輕點**：設定 › 輔助使用 › 觸控 › 背面輕點 → 輕點兩下或三下 → 選「八千代」。
- **嘿 Siri**：直接說「嘿 Siri，八千代」。

## 3. 已知行為

| 狀況 | 會發生什麼 |
|---|---|
| 電腦關機 / 睡眠 / Tailscale 沒連 | 步驟 12 跳出連線錯誤，捷徑停止；但紀錄**已經存在手機的 `inbox.txt`**，下次送成功時會整批補送 |
| 電腦連不到時 | 可能要等一陣子才逾時，屬正常 |
| Claude 回覆失敗（沒網路、金鑰錯） | 什麼都不念；這一次的內容不會被記錄 |
| 什麼都沒念 | 在「取得 URL 內容」後面暫時加 **快速查看**（URL 內容）看原始回應；常見：`invalid x-api-key`（金鑰前後多了空白/換行或沒複製完整）、碰到工作區花費上限 |
| 步驟 6 取值錯誤 | 第 3 個取辭典值要「在**來自列表的項目**中取得 `text`」，不是在 URL 內容中取 |

電腦端收到的內容在 `C:\Users\User\AppData\Local\YaChiYo\phone\inbox.md`。
