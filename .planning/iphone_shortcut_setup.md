## 1. 新增捷徑，命名「八千代」

依序加入下列動作（括號內是英文名稱，搜尋不到中文時可用）：

### A. 聽你說話
1. **聽寫文字**（Dictate Text）
   - 語言：中文（台灣）
   - 停止聽寫：暫停後

### B. 問 Claude
2. **文字**（Text）→ 貼上 Claude API 金鑰。
3. **取得 URL 內容**（Get Contents of URL）
   - URL：`https://api.anthropic.com/v1/messages`
   - 方法：**POST**
   - 標頭（Headers）新增三個：
     | 鍵 | 值 |
     |---|---|
     | `x-api-key` | 步驟 2 的「文字」 |
     | `anthropic-version` | `2026-10-21` |
     | `content-type` | `application/json` |
   - 要求本文：**JSON**，新增欄位：
     | 鍵 | 類型 | 值 |
     |---|---|---|
     | `model` | 文字 | `claude-haiku-5-5` |
     | `max_tokens` | 數字 | `1024` |
     | `thinking` | 辭典 | `type`（文字）= `disabled` |
     | `system` | 文字 | 見下方 |
     | `tools` | 陣列 | 一個**辭典**，內容見下方 |
     | `messages` | 陣列 | 一個**辭典**：`role`（文字）= `user`、`content`（文字）= 「已聽寫的文字」 |

   `system`（App 清單換成自己要的）：
   ```
   你是八千代，使用者的桌寵助理。用繁體中文、口語、簡短回答（兩三句以內），因為回覆會被朗讀出來。
   只有需要即時或你不確定的資訊（新聞、天氣、營業時間、價格等）才上網搜尋，其他直接回答；不要念網址、不要列來源。
   如果使用者要你打開 App，只能開這些：Spotify、YouTube、LINE。
   要打開時，在回覆最後另起一行寫：[開啟|App名稱]，名稱照清單寫，例如 [開啟|Spotify]。
   清單以外的 App 就說你還打不開，不要寫標記。
   ```

   `tools` 裡的辭典（上網搜尋）：
   | 鍵 | 類型 | 值 |
   |---|---|---|
   | `type` | 文字 | `web_search_20250305`（Haiku 用這版；`20260209` 只支援 Sonnet / Opus） |
   | `name` | 文字 | `web_search` |
   | `max_uses` | 數字 | `3`（一次最多搜 3 次，控制花費） |
   | `user_location` | 辭典 | （可省略）`type`=`approximate`、`country`=`TW`、`city`=`Taipei`、`timezone`=`Asia/Taipei` |

> `thinking` 一定要設 `disabled`：不然回覆裡會多一塊空的思考區塊。
> 費用：搜尋每次 $0.01（約台幣 0.3 元）＋搜尋結果的輸入 token；不需搜尋的對話不加錢。

### C. 取出回覆並朗讀
> 有搜尋時 `content` 會有好幾塊（搜尋動作 → 搜尋結果 → 一段段答案），所以要把所有 `text` 區塊接起來，不能只取第一個。

4. **取得辭典值**（Get Dictionary Value）→ 取得 `content` 的值，來源是步驟 3 的「URL 的內容」
5. **重複執行每一個**（Repeat with Each）→ 對象：步驟 4 的「辭典值」
   6. **取得辭典值** → 取得 `type` 的值，來源是「重複項目」
   7. **如果** → 步驟 6 的「辭典值」**是** `text`
      8. **取得辭典值** → 取得 `text` 的值，來源是「重複項目」
      9. **加入到變數**（Add to Variable）→ 變數名稱 `回覆`
   - 結束如果
   - 結束重複
10. **結合文字**（Combine Text）→ 變數「回覆」，分隔符號選「自訂」、留空 → 輸出「**結合的文字**」
11. **取代文字**（Replace Text）→ 把 App 標記去掉，不要念出來
    - 尋找：`\s*\[開啟\|[^\]]*\]`
    - 取代為：留空
    - 對象：「結合的文字」
    - 展開 › 打開「**正規表示式**」→ 輸出「**已更新的文字**」
12. **朗讀文字**（Speak Text）→「已更新的文字」，語言選中文（台灣）

### D. 紀錄先存手機
13. **文字** → 組成這次的紀錄：
    ```
    [目前日期] 我：已聽寫的文字
    八千代：已更新的文字
    ```
    「目前日期」點開後把格式改成「自訂」：`yyyy-MM-dd HH:mm`
14. **附加到文字檔案**（Append to Text File）
    - 「將 文字 附加到 **我的 iPhone**」：⚠️ 位置要選「我的 iPhone」，不要選 iCloud Drive
    - 檔案路徑：`inbox.txt`
    - 打開「**新增一行**」

### E. 開 App（八千代回覆裡有標記才開）
> 放在送電腦**之前**：電腦關機時步驟 18 會報錯讓捷徑停住，放後面的話 App 就開不了。紀錄已在步驟 14 存好，不會遺失。

15. 每個 App 一組（名稱要和 `system` 清單**完全一樣**）：
    - **如果** →「結合的文字」（**未去除標記**的那個）**包含** `[開啟|Spotify]`
      - **打開 App** → 選 Spotify
    - 結束如果

### F. 送到電腦，成功就清空
> 「附加到文字檔案」的輸出「**已附加的檔案**」就是 `inbox.txt` 本身，不需要再「取得檔案」
> （加了反而報「檔案路徑必須包含在目錄內」）。

16. **從輸入取得文字**（Get Text from Input）→ 輸入選「已附加的檔案」
17. **文字** → 貼上接收器 token（前後不要有空白或換行）
18. **取得 URL 內容**
    - URL：`http://100.102.217.57:39220/note`
    - 方法：**POST**
    - 標頭：`Authorization` = `Bearer ` + 步驟 17 的「文字」（**Bearer 後面有一個空格**）
    - 要求本文：**JSON**，一個欄位 `text`（文字）= 步驟 16 的「文字」
19. **如果**（If）→ 步驟 18 的「URL 內容」**包含** `true`
    - 若選單只有「包含任何數值」：在前面加「從輸入取得文字」把 URL 內容轉成文字，條件改用那個「文字」
    - 裡面放 **刪除** → 對象「**已附加的檔案**」，打開「立即刪除」
    - 結束如果（「否則」留空）
    - 不想每次跳確認：設定 › 捷徑 › 進階 › 打開「允許刪除而不需確認」

> ⚠️ 多個動作的輸出同名（好幾個「文字」「辭典值」「URL 內容」），而且「文字」動作不一定能改名 →
> 插入變數時選**最近的那一個**，選完再確認。

## 4. 已知行為與排錯

| 狀況 | 會發生什麼 / 怎麼查 |
|---|---|
| 電腦關機 / 睡眠 / Tailscale 沒連 | 步驟 18 跳連線錯誤、捷徑停止；紀錄**已在手機 `inbox.txt`**，下次送成功時整批補送 |
| 電腦連不到時 | 可能要等一陣子才逾時，屬正常 |
| 什麼都沒念 | 在步驟 3 後面暫時加 **快速查看**（URL 內容）看原始回應；常見：`invalid x-api-key`（金鑰多了空白/換行）、碰到工作區花費上限、Web search 未開放 |
| 回應有 `"stop_reason":"pause_turn"` | 搜尋還沒做完就停了 → `max_uses` 調成 2 |
| App 沒開 | 快速查看回覆裡有沒有 `[開啟|…]`、名稱是否和「如果」裡完全一樣 |
| 念出了 `[開啟|…]` | 步驟 11 沒打開「正規表示式」，或朗讀選到「結合的文字」而不是「已更新的文字」 |
| Claude 回覆失敗 | 什麼都不念；這一次的內容不會被記錄 |

電腦端收到的內容在 `C:\Users\User\AppData\Local\YaChiYo\phone\inbox.md`。
